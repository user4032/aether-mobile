ПЛАТФОРМУ.

LUMYN доступний на смартфонах і ПК. Захищене спілкування на всіх ваших пристроях.

Windows Installer

1
Натисніть Завантажити .EXE
2
Запустіть інсталятор та підтвердьте встановлення
3
Відкрийте LUMYN з ярлика на Робочому столі
Відкрити останній реліз
// ОБЕРІТЬ LumynMessengerSetup.exe У ВКЛАДЕННЯХ РЕЛІЗУ

iOS / iPadOS

1
Відкрийте сайт у Safari
2
Натисніть кнопку "Поділитися" знизу екрана
3
Виберіть "На екран Домів"
// SAFARI → ПОДІЛИТИСЬ → ДОМІВ

Android

1
Відкрийте сайт у Google Chrome
2
Натисніть меню ⋮ у верхньому правому куті
3
Виберіть "Додати на головний екран"
// ВСТАНОВЛЕННЯ ЧЕРЕЗ БРАУЗЕР
