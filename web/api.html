API

Публічний API шар LUMYN для клієнтів і інтеграцій. Версіонуй запити і перевіряй сумісність перед релізом.

Поточні події

  • auth/login/register/verify_email_code
  • get_recent_chats/get_direct_history/get_group_info/update_group
  • message/reaction/typing/presence/update_chat_settings

План оновлень API

  • Опис кодів помилок і retry-політика
  • Rate limit і abuse-protection для OTP
  • Стабільний schema contract для клієнтів
