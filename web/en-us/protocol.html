API Protocol Schema Moderation
// 01
Key Exchange
lumyn/core — key-exchange.flow
01
Key pair generation
Client generates X25519 key pair locally during registration. Private key is stored in flutter_secure_storage and never leaves the device.
X25519 · flutter_secure_storage
02
Public key publication
Public key is registered on Socket.IO server. Server acts only as key server — cannot decrypt any message.
Socket.IO · Node.js
03
ECDH shared secret
When opening chat, client receives counterparty's public key and computes shared secret via X25519 ECDH. Shared secret is never transmitted over network.
Elliptic Curve Diffie-Hellman
04
Session key derivation
From shared secret, session key for AES-256-GCM encryption is derived via HKDF. Unique nonce is generated for each message.
HKDF · AES-256-GCM · cryptography package
// 02
Message Encryption
Algorithm
AES-256-GCM
Authenticated encryption with additional data. Each message is individually encrypted.
Key Exchange
X25519
Elliptic Curve Diffie-Hellman on Curve25519. Fast and resistant to attacks.
Nonce
96 bit
Unique per-message nonce ensures same plaintext always encrypts differently.
MAC
GCM tag
128-bit authentication tag verifies integrity and authenticity of each message.
// 03
Transport and Delivery
lumyn/transport — socket-events
→
sendMessage
Client sends encrypted payload. Server routes to recipient or group without seeing content.
→
sendGroupMessage
Group messages support group shared secret or per-member encryption depending on settings.
→
sendEphemeral / sendEphemeralGroup
Ephemeral messages marked with isEphemeral flag. Deleted from memory after delivery confirmation. Client deletes after viewing.
→
sendVoice / sendImage
Media files are encrypted with separate key, encoded in base64 and transmitted as part of payload.

Volatile Memory Model
Server Architecture
// Server has no database for messages // All state stored exclusively in RAM const activeConnections = new Map(); // socket per user const publicKeys = new Map(); // public keys only const offlineQueue = new Map(); // temp until delivery // After delivery — message is destroyed // After disconnect — session is cleared // Zero persistent storage for message content

Protocol Roadmap
Implemented
X25519 + AES-256-GCM E2E
Full end-to-end encryption for direct and group chats, voice and media messages.
Implemented
Ephemeral Messages
Ephemeral messages for direct chats and groups that disappear after viewing on all devices.
In Progress
Multi-device Synchronization
Secure session sync across devices without compromising Zero-Knowledge architecture.
Planned
Forward Secrecy
Key rotation to ensure current key compromise doesn't reveal past messages.
Planned
Open Source
Public audit of cryptographic code for client and backend.
